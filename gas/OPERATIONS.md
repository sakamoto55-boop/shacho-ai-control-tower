# 事務担当者向け 運用マニュアル

## 毎日の流れ

このシステムは **平日の朝8時・13時・16時** に自動でメールを確認します。  
対応が必要なメールがあれば、LINE WORKS に通知が届きます。

---

## 1. LINE WORKS 通知が来たら

通知の例：

```
【Infoメール対応】新規タスク 2件

[高] 山田太郎／外構工事のお見積もりについて
送信者：yamada@example.com
要約：駐車場拡張とフェンス設置の見積依頼。現地確認希望あり。
対応：営業担当を決め、現地調査候補日を返信する。
担当候補：営業
期限目安：今日中
下書き：作成済み
タスク：https://docs.google.com/spreadsheets/d/...
---
[中] 鈴木工業／明日の入場時間について
...
```

**見るべきポイント**：
- `[高]` のタスクから優先して対応する
- 「タスク：」のリンクからスプレッドシートの詳細を確認する
- 「下書き：作成済み」の場合は Gmail に返信案があります

---

## 2. スプレッドシートの見方

「タスク：」のリンクをクリックするとスプレッドシートの該当行が開きます。

| 列名 | 内容 |
|---|---|
| 優先度 | 高 / 中 / 低 |
| ステータス | 現在の対応状況 |
| カテゴリ | メールの種類 |
| 担当候補 | AI が推測した担当部署 |
| 送信者 | メールの送信者 |
| 件名 | メールの件名 |
| 要約 | AI が作成した3行要約 |
| 対応タスク | 次にやるべき具体的な対応 |
| 返信案 | AI が作成した返信文 |
| 期限目安 | 対応推奨期限 |
| リスクメモ | 金額・契約・クレームなどの注意点 |
| Gmailリンク | 元のメールを開くリンク |
| 下書きID | Gmail の下書き ID |

---

## 3. ステータスの変更方法

スプレッドシートの「ステータス」列をクリックすると、プルダウンが表示されます。

| ステータス | 使うタイミング |
|---|---|
| 未対応 | 初期値。まだ対応していない |
| 対応中 | 担当者が確認・対応中 |
| 完了 | 返信済み・対応完了 |
| 保留 | 上長確認中・情報待ち |
| 対応不要 | 実際には対応不要と判断した場合 |

---

## 4. Gmail 下書きの確認方法

1. スプレッドシートの「Gmailリンク」列（「開く」リンク）をクリックする
2. 元のメールが Gmail で開く
3. Gmail の「下書き」フォルダを開くか、スレッド内の下書きを確認する
4. 返信案の内容を確認・修正する
5. 内容に問題がなければ「送信」ボタンをクリックする

> ⚠️ AI が自動送信することはありません。かならず担当者が確認してから送信してください。

---

## 5. 返信前に確認すべきこと

返信を送る前に、以下を必ず確認してください。

**全般**
- [ ] 宛先が合っているか
- [ ] 送信者の名前・会社名に誤字がないか
- [ ] 日付・曜日・時間などの情報が正確か
- [ ] 不明な点を「確認します」として保留にしているか

**見積依頼の場合**
- [ ] 金額・工期を勝手に約束していないか
- [ ] 現地確認の日程調整が未確定になっているか
- [ ] 担当営業が誰になるかを確認してから返信するか

**クレームの場合**
- [ ] 謝意は示しているが責任・補償を認める表現がないか
- [ ] 事実確認をする旨が記載されているか
- [ ] 必要に応じて代表または担当者に確認してから返信するか
- [ ] 返信前に上長に報告しているか

**請求・契約関係**
- [ ] 金額・支払い条件を勝手に確定していないか
- [ ] 経理または担当者への確認が含まれているか

---

## 6. クレーム・金額・契約・工期が絡む場合

以下の案件は、**かならず代表または担当者に確認してから返信**してください。

- クレームや苦情（工事の仕上がり、遅延など）
- 見積金額の提示
- 工期・完工日の約束
- 契約内容の変更・確認
- 損害賠償・補償に関する問い合わせ
- 行政・金融機関・士業（弁護士・税理士など）からの連絡

AI の返信案は「確認してからご連絡します」という内容になっていますが、  
最終確認は必ず人間が行ってください。

---

## 7. 対応完了後の記録方法

1. スプレッドシートの「ステータス」を「完了」に変更する
2. 「対応者」列に自分の名前を記入する
3. 「完了日時」列に完了した日時を記入する（例: 2026/06/14 10:30）
4. 必要に応じて「対応メモ」列に対応内容を記入する

記録例：
```
対応者: 田中
完了日時: 2026/06/14 10:30
対応メモ: 営業の佐藤に確認し、6/17（水）午後に現地調査を予定。その旨を返信済み。
```

---

## 8. AI 判定がおかしい場合の報告方法

以下のようなケースは、担当エンジニアに報告してください。

**報告すべき事例**:
- 重要なメールが「対応不要」と判定された
- 明らかな広告・スパムが「高優先度」でタスク登録された
- 返信案の内容がおかしい（金額確定・責任認定の表現が含まれる等）
- AI 判定がほぼ毎回間違うカテゴリがある

**報告方法**:
1. スプレッドシートの該当行を特定する
2. 「メッセージID」列の値をコピーする
3. 実際のメールの件名・送信者・判定結果・何が問題かをエンジニアに伝える

AI の判断精度は運用しながら改善できます。おかしな判定を見つけたら積極的に報告してください。

## よくある質問

**Q. LINE WORKS 通知が来なかった場合、メールは処理されていない？**  
A. 処理は済んでいてもエラーで通知が失敗した可能性があります。スプレッドシートの「処理ログ」シートを確認してください。

**Q. 同じメールが2回登録された場合は？**  
A. スプレッドシートで重複している行の片方を手動で削除してください。エンジニアにも報告をお願いします。

**Q. スプレッドシートの行を誤って削除した場合は？**  
A. エンジニアに連絡してください。処理ログから復元できる場合があります。

**Q. メールの優先度が低いと判定されたが、実際は高優先度だった**  
A. スプレッドシートの「優先度」プルダウンを手動で変更してください。エンジニアへの報告もお願いします。

**Q. 土日は通知が来ない？**  
A. 来ません。月曜日の8時台に土日分もまとめて処理されます。

**Q. 祝日も自動で止まる？**  
A. 現時点では祝日の自動判定は実装していません。土日は停止しますが、祝日は実行されます（新着がなければ「対応不要メールなし」の通知が来ます）。
