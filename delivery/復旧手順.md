# 復旧手順 — LCC COMMAND（PC故障・入替時）

1. 新PCに Node.js 20+ を入れ、納品ZIPを展開（または `git clone`）
2. `npm install`
3. バックアップの `data/` `.env` `secure/` を同じ場所へ戻す
4. `npm run command:beta` → 全条件PASSを確認
5. `start-lcc-command.bat` で起動

これで記憶・憲法・目標・Incident・Growth履歴を含め完全復旧します。
バックアップが無い場合: 実データ（Sheets）は無傷ですが、AIの記憶・承認履歴は失われます。
