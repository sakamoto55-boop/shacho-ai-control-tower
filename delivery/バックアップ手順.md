# バックアップ手順 — LCC COMMAND

## 対象（この3つだけ）
| 対象 | 内容 |
|---|---|
| `data/` | 記憶・会社憲法・目標・Incident・Growth・実験・生成物（システムの頭脳） |
| `.env` | 接続設定・APIキー |
| `secure/` | Google Service Account鍵 |

## 手順（Windows・毎日推奨）
1. メモ帳に貼って `backup.bat` として保存:
```
xcopy C:\lcc-command\data D:\backup\lcc\data /E /Y /I
copy C:\lcc-command\.env D:\backup\lcc\ /Y
xcopy C:\lcc-command\secure D:\backup\lcc\secure /E /Y /I
```
2. タスクスケジューラで毎日実行（例: 21:00）
※実データ（顧客・案件）の正本はGoogle Sheets側にあり、システムには複製されません（READ ONLY）
