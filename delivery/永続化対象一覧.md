# 永続化対象一覧（保存先と再起動・故障時の挙動）

| データ | 保存先 | 再起動 | PC故障 | 備考 |
|---|---|---|---|---|
| Memory・会社憲法・目標・Incident・Growth・実験・承認・判断 | `data/lcc-command-local.json`（ローカルJSON） | 残る | バックアップ必須 | 2026-08-08停止→再起動テストで保持確認済み |
| Growth観測履歴 | `data/growth-snapshots.jsonl`（JSONL） | 残る | バックアップ必須 | |
| 生成物（PPTX/XLSX/PDF） | `data/artifacts/`（ファイル）+ Registry | 残る | バックアップ必須 | |
| 実データ（顧客・案件） | Google Sheets（正本・READ ONLY） | 残る | 残る | システム側に複製なし |
| 会話セッション文脈 | メモリ内 | 消える | — | 重要事項はMemoryへ保存済みのため実害なし |
| Audit Log / Observability / Provider実績 | メモリ内リングバッファ | 消える | — | 既知の制約。JSONL永続化はenv `LCC_COMMAND_OBS_FILE` で可 |
