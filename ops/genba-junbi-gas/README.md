「水曜くらいから現場準備台帳の LINE WORKS 報告が止まった」という相談から調査した。

**故障ではなかった。** 会社カレンダー「LCC株式会社」の 8/13〜8/16 に「休日」の終日予定があり、

調査の過程で、別に直すべき不具合が見つかったので修正した。
