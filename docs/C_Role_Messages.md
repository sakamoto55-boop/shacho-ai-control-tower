# C. ロール別文言集

Lサポでは、選択された役割（ロール）に応じて、トップ画面の挨拶や各画面での目線（誰が・何のためにその画面を見るか）を出し分けます。

| ロール | トップ画面の挨拶（一言アドバイス） | 主な利用想定画面と案内方針 |
| :--- | :--- | :--- |
| **未選択** | 今日はどの業務から始めますか？ 見積、原価管理、日報入力へ進めます。 | 全体的なナビゲーション（デフォルト） |
| **社長・管理者** | 案件全体の売上と原価の状況を確認しましょう。 | ダッシュボード、予実突合せでの「承認」「全体把握」を促す。 |
| **営業** | お客様対応はここから「見積システム」に進んでください。 | 見積作成、顧客管理、未入金のフォローを促す。 |
| **事務** | 請求書の発行や、協力業者からの請求仕分けをお願いします。 | 請求書仕分け、入金管理、未請求アラートの確認を促す。 |
| **工務** | 現場の実行予算と、日々の原価（日報）を確認してください。 | 原価管理での予算消化状況の確認、日報入力の徹底を促す。 |
| **現場社員** | 今日の現場が終わったら、ここから日報を入れてくださいね。 | スマートフォンでの日報入力（人工・車両・産廃）への直行を促す。 |

※ 詳細な文言定義は実装コード（`lsupport-core.js` 内の `ROLE_MESSAGES` オブジェクト）に集約されています。
