# ROLE_SEPARATION.md — ツール役割分担表

> 各AI・各サービスの役割を明確に分け、重複と混乱を防ぐ  
> 2026-06-27

---

## 一覧

| ツール | 主な役割 | 使う場面 | 課金 |
|--------|---------|---------|------|
| **ChatGPT** | 日々の実務運用 | 毎日 | サブスク（任意）|
| **Claude Code** | 専用アプリ開発 | 開発・改修時 | 開発時のみ |
| **Gemini** | Google設定/OAuth/Workspace補助 | 設定時 | 無料枠中心 |
| **Manus** | 資料・マニュアル・デザイン補助 | 必要時 | 任意 |
| **GitHub** | 保管・公開・バージョン管理 | 常時（自動）| 公開は無料 |

---

## ChatGPT — 日々の実務運用

**役割**: 社長の手元の相談相手。今日から実務を回す。

- Gmail / Calendar / Drive の内容を確認・要約
- 返信文・連絡文の下書き作成（送信は社長が手動）
- 優先順位の相談、判断材料の整理
- アプリの本番接続を待たずに実務が回る

**やらないこと**: アプリのコードを書く（→ Claude Code）

---

## Claude Code — 専用アプリ開発

**役割**: AI社長室アプリそのものを作る・直す・本番接続する。

- 機能追加・改修・バグ修正
- Provider / AI Engine / 画面の実装
- Gmail等の本番接続（OAuth・バックエンドProxy）
- ドキュメント・設計書の整備
- GitHub へのコミット・デプロイ

**やらないこと**: 日々の実務代行（→ ChatGPT）

---

## Gemini — Google設定/OAuth/Workspace補助

**役割**: Google まわりの設定相談。

- Google Cloud Console の OAuth Client ID 設定支援
- Workspace / Gmail / Calendar の権限・スコープ相談
- Google 側のエラー解決補助

**やらないこと**: アプリ開発（→ Claude Code）/ 日々の実務（→ ChatGPT）

---

## Manus — 資料・マニュアル・デザイン補助

**役割**: 見せる・伝えるための成果物作成。

- 操作マニュアル・社内説明資料
- 図版・スライド・デザイン補助
- 非エンジニア向けの資料化

---

## GitHub — 保管・公開・バージョン管理

**役割**: すべての成果物の置き場所と履歴管理。

- ソースコード・ドキュメントの保管
- バージョン管理（コミット履歴）
- GitHub Pages による公開URL配信
- GitHub Actions による自動ビルド・デプロイ（公開リポジトリは無料）

---

## 棲み分けの原則

```
「今日の実務」        → ChatGPT
「アプリを作る/直す」  → Claude Code
「Google設定で困った」→ Gemini
「資料を作る」        → Manus
「保管・公開・履歴」  → GitHub
```

迷ったら: 実務はChatGPT、開発はClaude Code。
