### 2. App.tsx — OAuth コールバック処理

**変更内容**: Google からのリダイレクト（`?code=...&state=...`）を自動検知

**確認すべき箇所**:

| 状況 | 期待する動作 |
|------|------------|
| 通常起動 | `?code` なし → 通常ホーム画面 |
| OAuth 成功後リダイレクト | `?code=...&state=...` → 設定画面に遷移、「接続済み」表示 |
| OAuth エラーリダイレクト | `?error=access_denied` → 設定画面に遷移、エラー表示 |
