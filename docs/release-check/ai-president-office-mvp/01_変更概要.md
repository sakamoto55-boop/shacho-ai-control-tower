## 方針
LCC仕様書（実行マスター / MVP実装仕様書 / Claude Code実装指示書）の7領域を、
**既存リポジトリを流用し非破壊で**実装。別プロジェクト新規作成・大規模リファクタリングはしない。
仕様書推奨のNext.js/Supabase/Vercelへは作り替えず、既存 React+Vite+既存AI Engine を再利用。

## 実装した7領域（AI社長室トップ = 既存Home画面に集約カードを追加）
1. 今日の予定（Schedule Provider / Calendar実データ対応）
2. 要対応メール（Inbox/Gmail・優先度A/B・未返信）
3. 社長確認待ち（approvalQueue・表示のみ）
4. 期限超過タスク（受信箱の期限を解析し超過を抽出）
5. 進行中プロジェクト（案件別粗利シート由来 / 実源未設定はデモ明示）
6. AIの今日の優先順位（decisionEngine TOP3）
7. 相談・指示チャット導線（既存AiChatへ遷移）
