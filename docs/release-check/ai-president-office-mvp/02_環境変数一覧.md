# 02_環境変数一覧 — AI社長室MVP

> 秘密情報はコードに直書きしない。`.env` は `.gitignore` 済み。`.env.example` は変数名のみ。

## フロント（client/.env）
| 変数 | 用途 | 必須 |
|------|------|------|
| VITE_GOOGLE_CLIENT_ID | OAuth クライアントID | 実データ化に必須 |
| VITE_GOOGLE_REDIRECT_URI | コールバックURI（Consoleと一致）| 実データ化に必須 |
| VITE_GOOGLE_SCOPES | 4スコープ すべて readonly（gmail/calendar/drive/spreadsheets）| 実データ化に必須 |
| VITE_GOOGLE_SHEETS_SALES_ID | 売上シートID | 任意（未設定はデモ）|
| VITE_GOOGLE_SHEETS_CASHFLOW_ID | 資金繰りシートID | 任意 |
| VITE_GOOGLE_SHEETS_PROJECT_PROFIT_ID | 案件別粗利（進行中プロジェクト源）| 任意 |
| VITE_GOOGLE_SHEETS_RECEIVABLE_ID | 売掛シートID | 任意 |
| VITE_GOOGLE_SHEETS_PAYABLE_ID | 買掛シートID | 任意 |

## バックエンド（root .env・MVPはフロント単体で可）
| 変数 | 用途 |
|------|------|
| NODE_ENV / PORT | 実行環境 |
| AI_PROVIDER | 既定 mock（実AI APIは使わない）|
| OPENAI_API_KEY / ANTHROPIC_API_KEY | 空欄（未使用・休眠）|

## 禁止
- Client Secret はフロントに置かない（本アプリは使用しない）
- 実シートID・実トークン・APIキーをコード/README/コミットに含めない
