# AI社長室 v1.0.0 — 現在できること・できないこと

> Phase 10 完了 · 2026-06-27 現在

---

## ✅ 現在できること

### デモデータで AI社長室を確認

- Gmail / Calendar / Drive / Sheets / LINE WORKS を想定したデモ画面を全て確認できます
- 実際のAPIキーなし、ログインなしで動作します
- スマホ・PCどちらでもアクセスできます

### AI優先順位の確認

- 全5Providerのデータを横断したAI優先順位TOP7を確認できます
- 緊急度（critical / high / medium）の色分けで一目でわかります
- 各アイテムに「なぜ優先か」の理由と「推奨アクション」が表示されます

### 会社健康度の確認

- 9カテゴリ（資金繰り・粗利率・未請求・未回収・事故・人員・売上・社内SOS・予定負荷）のスコアを確認できます
- A/B/C/Dのグレードで会社全体の健康状態が一目でわかります
- リスクカテゴリの警告が表示されます

### 承認待ちアクションの確認（表示のみ）

- 社長承認が必要なアクションの下書きを確認できます（最大6件）
- 返信下書き・対応連絡下書き・確認依頼下書きの3種類が生成されます
- **送信・保存・実行は行われません（表示・確認のみ）**

### 朝ブリーフィングの確認

- 今日の状況サマリー・注目事項を確認できます
- AI相談「朝ブリーフィングを読んで」でいつでも確認できます

### AI相談（デモ回答）

- 8つの統合ショートカット質問への回答を確認できます
- LINE WORKS専用・Gmail専用ショートカットも使えます
- 自由入力のテキスト相談（デモ回答）ができます

### 経営数値の確認（デモデータ）

- 月次売上・粗利・13週資金繰りグラフを確認できます
- 案件粗利ランキング・部署別利益を確認できます
- デモの経営指標がそのまま表示されます
