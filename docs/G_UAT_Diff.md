# G. 既存8091版（v2）との差分説明

このドキュメントでは、前回の試作版（8091・v2）から、今回の最終版（A案固定版・v3）への変更点について説明します。

## 1. デザインのA案（LCCロゴ型・ネイビー）固定化

- **デフォルトデザインの固定**：
  前回のv2版ではA/B/Cの3案を切り替え可能でしたが、今回は**A案（LCCロゴ型・ネイビー）を正式採用とし、デフォルトとして固定**しました。
  - FABアイコン：角丸四角の中に太字の「L」
  - テーマカラー：ネイビー（`#0a2a5e`）
  - パネルヘッダー：LCCロゴ調のアイコン

- **切替ボタンの非表示化（通常ユーザーモード）**：
  パネル下部にあった「表示デザイン：A B C」の切替ボタンを、**通常ユーザーには非表示**（`display: none`）にしました。これにより、一般ユーザーが誤ってデザインを変更してしまうことを防ぎ、常にA案が表示されます。

- **開発者モード（検証用）の維持**：
  B案・C案のデータ自体はコード内に保持しており、検証用として以下の方法でアクセスした場合のみ、切替ボタンが表示されます。
  - URLパラメータに `?lsup_dev=1` を付与してアクセス
  - URLパラメータに `?lsup=b` または `?lsup=c` を付与してアクセス

## 2. 既存UAT環境（8090）への影響

- **影響ゼロ**：
  今回も既存のUAT環境（ポート8090）には一切触れていません。修正はすべて別ステージング環境（ポート8091）上で行われました。

## 3. その他の維持された仕様

以下の仕様はv2版から変更なく維持されています。

- **業務サポート係口調**：キャラ口調を排除した、客観的で信頼感のある案内文。
- **控えめな表示制御**：
  - FABサイズ：PC/iPad 48px、スマホ 44px
  - 吹き出し：初回アクセス時および注意・警告がある場合のみ表示
  - バッジ：注意がある場合のみ、控えめなサイズ・色で表示
- **非表示・スヌーズ機能**：「しばらく非表示」および完全非表示（`hide()`）が機能します。
- **アクセシビリティ・モバイル対応**：スマホ・iPadでも下部ナビゲーションと重ならず、Console Errorもゼロです。

## 4. 本番反映手順（変更なし）

本番環境（または8090環境）へ反映する際の手順は前回と同じです。
各HTMLファイル（`index.html`, `lcc.html`, `lcc-cost.html`）の `</body>` タグの直前に、Lサポの `<script>` ブロック（アダプタ＋本体）を追記するだけで完了します。既存のコードやDOM構造を書き換える必要はありません。
