# D. 画面別文言集

各画面（アプリ内のタブやサブ状態）でLサポが案内する内容の定義です。

## 1. ポータル（トップ画面）
* **この画面でできること**: 今日はどの業務から始めますか？ 見積、原価管理、日報入力へ進めます。
* **次にやること**:
  1. お客様の見積をつくる → 「見積システム」を開く
  2. 現場の原価・日報を入れる → 「原価管理」を開く
* **ショートカット**: 見積システムを開く / 原価管理を開く

## 2. 見積システム (lcc.html)
### 2.1 ダッシュボード
* **この画面でできること**: 案件の件数・売上・入金状況をひと目で確認できます。気になる案件は一覧から開けます。
* **次にやること**:
  1. 新しい見積をつくる → 下の「案件」から案件を選ぶ
  2. 入金の遅れを見る → 「入金」タブを確認
* **警告**: ▲請求済みで未入金の案件があります。入金予定をご確認ください。

### 2.2 案件編集（積算）
* **この画面でできること**: 見積の明細（大項目・中項目）を作成します。粗利率はここで調整できます。
* **次にやること**:
  1. 明細を追加する → 「＋大項目」「＋項目追加」
  2. お客様に出す → 「見積書」タブでPDF作成
* **警告（受注ロック時）**: 🔒 この案件は受注済みのためロックされています。変更するには「ロック解除」が必要です。

## 3. 原価管理 (lcc-cost.html)
### 3.1 案件一覧（予実）
* **この画面でできること**: 案件ごとの実行予算と実績原価を一覧で確認できます。まず対象の現場を選んでください。
* **次にやること**:
  1. 見積から予算を取り込む → 「設定」の「取り込む」
  2. 現場の実績を入れる → 「日報」タブへ
* **警告**: 
  * 🔴 予算をオーバーしている案件があります！
  * 🟡 予算の80%を超えた案件があります。
  * ▲ 完工したのに未請求の案件があります。請求書の作成をご確認ください。

### 3.2 日報入力
* **この画面でできること**: 現場・日付を選んで、人工・車両・産廃をタップで入力します（金額は自動計算）。
* **次にやること**:
  1. 現場を選ぶ → 一番上のプルダウン
  2. 実績を入れる → 「日報を入力する」をタップ
* **ショートカット**: 案件一覧に戻る / 請求仕分けへ

### 3.3 請求書仕分け
* **この画面でできること**: 協力業者から来た請求書を、どの現場でいくら使ったか振り分けます。
* **次にやること**:
  1. 請求書を手元に用意する
  2. 業者を選んで金額を入力する

※ 上記は代表的な画面の抜粋です。全画面の定義は `lsupport-core.js` の `SCREEN_MESSAGES` に記述されています。
