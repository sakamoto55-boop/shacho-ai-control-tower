# H. 本番導入時の影響範囲

Lサポ機能を本番環境へ導入する際の影響範囲と、安全にデプロイするための確認事項です。

## 1. 既存システムへの影響：極小（非破壊）
本モジュールは、既存のVue.jsや素のJavaScriptの内部ロジックに一切干渉しない「DOMオーバーレイ型＋状態の読み取り専用（Read-Only）」で設計されています。
そのため、**既存の業務ロジック、計算処理、データ保存処理への影響はゼロ**です。

## 2. パフォーマンスへの影響
* **ファイルサイズ**: 各HTMLファイルに約30KB〜35KBのテキストが追加されます。CDN等の外部通信は発生しないため、ロード時間の増加は体感できないレベル（数ミリ秒）です。
* **メモリ・CPU**: LサポのUI描画と、画面クリック時等の軽量な状態判定のみ実行されるため、ブラウザのパフォーマンスへの影響は極めて軽微です。

## 3. UI/UXへの影響と配慮事項
* **画面領域の占有**: 画面右下にアイコンが常駐します。モバイル端末では、既存の下部ナビゲーションバー（案件・日報など）と重ならないよう、自動的に底上げ（`bottom: 80px` 程度）して配置されます。
* **非表示機能**: 業務の邪魔になる場合は「しばらく非表示」ボタンで消すことができ、リロード後も非表示状態が維持されます。

## 4. 本番デプロイ時の手順
本番環境への導入は、今回の試作と同様に、各HTMLファイルの `</body>` 直前に指定の `<script>` ブロックをコピペして追記するだけで完了します。ビルドやサーバー側の設定変更は一切不要です。

## 5. 留意事項（フォールバック動作）
見積システム（`lcc.html`）において、本番環境ではセキュリティ上 `window.__lccApp`（Vueインスタンス）が公開されない仕様になっています。
Lサポのアダプタはこれを想定しており、インスタンスが読めない場合は、**URLのハッシュ（`#`）や画面上の特定のDOM要素（受注ロックの帯など）を見て画面状態を推定するフォールバックモード**で動作します。そのため、本番環境でもエラーで停止することなく、適切な案内が表示されます。
