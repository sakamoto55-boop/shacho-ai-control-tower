# A. Lサポ（常駐サポートキャラクター）機能仕様書

## 1. 概要
LCC統合業務アプリの各画面（ポータル・見積・原価）に常駐し、ユーザーの役割（ロール）や現在の画面状態に応じて、迷わず操作できるようナビゲーションを行うサポートキャラクター機能です。

## 2. 基本仕様
* **表示位置**: 画面右下に常駐（モバイル時は下部ナビゲーションバーを避けて底上げ配置）。
* **UI構成**: 
  * 待機時: 丸いアイコン（Lサポ顔アイコン）＋通知バッジ
  * パネル展開時: ヘッダー（現在画面・ロール）、今の注意ポイント（警告時のみ）、この画面でできること、次にやること（番号付き）、かんたん移動（ショートカットボタン）、役割選択、非表示ボタン。
* **実装方式**: 既存のVue.jsアプリやJavaScriptに一切干渉しない「自己完結型モジュール」として各HTMLの `</body>` 直前に埋め込み。
* **データ保持**: localStorage (`lcc_lsupport_pref_v1`) に「役割」「非表示状態」のみを保存。機密データ（案件・顧客・金額）は一切保存・送信しません。

## 3. 主要機能
1. **ロール（役割）別案内**: 社長・管理者、営業、事務、工務、現場社員の5ロールに応じたメッセージの出し分け。
2. **画面別案内**: 現在開いている画面（タブ・サブ画面）を自動検知し、その画面の目的と次の操作を案内。
3. **状態検知と警告**: 
   * **見積システム**: 受注ロック状態の検知、請求済み未入金の検知。
   * **原価管理**: 予算超過（100%超）、予算逼迫（80%超）、完工済み未請求の検知。
4. **ショートカット移動**: パネル内から目的の画面へ、既存の安全な遷移関数（`lccNav` 等）を経由して1タップで移動。
5. **アクセシビリティ**: `aria-label` の設定、キーボード操作（Escで閉じる等）、フォーカストラップ制御。

## 4. 技術的制約事項（遵守済み）
* 既存のグローバル関数（`window.go` 等）と競合しないよう、`window.LSupport` 名前空間に完全分離。
* 外部アセット（画像ファイル等）に依存せず、アイコン等はSVGインラインまたは絵文字を使用。
* 1HTMLファイル完結の要件を満たすため、CSS（Tailwindクラス）とJSロジックをすべてインライン化。
