# B. Lサポ UI配置およびデザイン仕様（最終版・v3）

## 1. 採用デザイン：A案（LCCロゴ型・ネイビー）固定

業務アプリとしての信頼感を損なわず、控えめで邪魔にならないデザインとして、**A案（LCCロゴ型・ネイビー）を正式採用とし、デフォルトとして固定**しました。

- **外観**: 角丸四角の中に太字の「L」の字（LCCの頭文字）。ネイビー基調。
- **特徴**: コーポレートカラーに馴染む最も無難なデザインです。顔や表情といったキャラクター感を完全に排除し、単色ラインで表現しています。業務システムとしての品位を落とさず、社長から現場社員まで誰が押しても違和感がありません。
- **切替ボタンの非表示化**: パネル下部にあったデザイン切替ボタン（A B C）は、通常ユーザーには非表示としています（開発者モード `?lsup_dev=1` のみ表示）。

## 2. UI配置と表示制御

- **常駐位置**: 画面右下（`bottom: 92px`, `right: 16px`）
- **サイズ**: PC/iPadでは 48px の丸ボタン、スマホでは 44px の丸ボタン
- **通常表示**: アイコン枠 ＋ 小さく「Lサポ」の文字。目立つ「？」文字は非表示。
- **バッジ**: 注意事項がある場合のみ、控えめなサイズ（15px）・低彩度の赤で右上に件数を表示。
- **モバイル配慮**: 画面下部の主要ボタン（「保存する」「この案件を削除」等）と重ならないよう底上げ配置。
- **吹き出し**: 初回アクセス時のみ短く表示。以後は「注意があるとき」のみ表示し、画面遷移ごとにうるさく出ないよう抑制。
- **非表示制御**: パネル内の「しばらく非表示」で30分間のスヌーズが可能。完全非表示（`hide()`）もサポート。
