## まず最初にやること

### URLを開く

```
https://sakamoto55-boop.github.io/shacho-ai-control-tower/
```

スマホのブラウザ（Safari / Chrome）でそのまま開けます。  
アプリのインストールは不要です。

> **注意**: 初回アクセス時は GitHub Pages が有効化されていることが前提です。  
> まだ有効化されていない場合は開発担当者に連絡してください。

### ホーム画面に追加する（任意）

**iPhone の場合：**
1. Safari でURLを開く
2. 下部の共有ボタン（四角に↑）をタップ
3. 「ホーム画面に追加」を選択
4. 「追加」をタップ

アプリのようにホーム画面から直接起動できます。

## 各画面の見方

### 🏠 ホーム画面

**毎朝最初に確認する画面です。**

| 場所 | 見るもの |
|------|---------|
| 上部のブリーフィングカード | 今日の状況サマリー・注目事項 |
| 会社健康スコア | 会社全体の健康状態（A/B/C/D） |
| LINE WORKSカード | 緊急通知の件数・SOSの有無 |
| Gmailカード | 要対応メールの件数 |
| クイックアクション | AI相談・経営ダッシュボードへの導線 |

**使い方のコツ：**  
→ ブリーフィングカードの「今日の優先判断を見る」ボタンをタップして AIコックピットに移動してください。

### 🎯 AIコックピット（下部ナビ：コックピット）

**今日の判断を行う画面です。最重要。**

#### 📊 会社健康スコア
- 総合グレード（A/B/C/D）と0〜100点のスコアが表示されます
- 9カテゴリ（資金繰り・粗利率・未請求・未回収・事故・人員・売上・社内SOS・予定負荷）のグレードを確認できます
- 赤・黄の警告が出ているカテゴリに注目してください

#### 🎯 今日の優先判断 TOP5
- AIが全データを横断して「今日対応すべき順番」にまとめたリストです
- 各カードに「なぜ優先か」の理由と「推奨アクション」が書いてあります
- **⚡今すぐ対応**（赤・橙）が表示されている場合は最優先で確認してください

#### ✅ 社長承認キュー
- 黄色（amber）セクションに表示される返信下書き・確認依頼です
- **現バージョン（v1.0.0）ではUIと型の確認のみ。実際の送信・保存は行われません**
- 内容を確認し、次のアクションを決めてください

#### 💬 LINE WORKS通知
- ティール（緑）セクションに緊急通知・社内連絡が表示されます
- 赤いカードはSOS・事故報告です。必ず確認してください

## よくある質問

**Q: データが本物ではないの？**  
A: はい、v1.0.0 は全デモデータです。Gmail・Calendar・Drive・Sheets・LINE WORKS はすべてモックデータを表示しています。実データを接続するには Phase 11 の本番接続作業が必要です。

**Q: 承認ボタンを押したら実際に送信される？**  
A: されません。現バージョンでは承認フローはUI表示のみです。実際の送信は Phase 11 以降です。

**Q: スマホで使えない？**  
A: iPhone Safari / Android Chrome の最新版で動作確認しています。画面が崩れる場合はページを再読み込みしてください。

**Q: オフラインで使える？**  
A: ページを一度読み込めば、デモデータはオフラインでも閲覧できます（一部機能制限あり）。
